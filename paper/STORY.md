# BorrowedSight 论文故事

故事只留一根轴：没有本车环境观测时，邻车消息是唯一证据；没传到的体素不等于安全空闲。

本文件只锁题目、贡献、相关工作缺口和章首过渡。没有真实日志之前不写结果表，不写 mIoU，不写 UFE，也不写任何实验数字。工程约束和停止判据在仓库根目录的 `CLAUDE.md`。

## 题目

英文：

BorrowedSight: Receiver-Centric Category-Geometry Token Communication for Zero-Ego-Observation Cooperative 3D Occupancy

中文：

BorrowedSight：面向零本车环境观测的接收端中心类别几何 Token 协同三维语义占据

这个题目锁定。下面两个旧题目不再使用：把恶劣天气放进主位的题目，以及把发送端写成相机加激光雷达联合输入的题目。天气只作为 LISA 测试条件。发送端只读邻车激光雷达点云。

## 三条贡献

1. 零本车环境观测协议。接收端只使用自身位姿、时间、车辆状态和邻车消息。本车相机、激光雷达以及由它们算出的特征都不得进入网络。协议用泄漏测试检查，而不是把某个张量乘零就声称成立。关掉全部邻车消息之后，输出只能退回先验或未知。

2. 同一套网络下的几何与可见性通信。发送端用 `ResidualSimVQ(rotation_trick=True)` 做残差量化。预测头保持十二类，几何码本只分成 Things、Ground、Vertical Static 三组。低带宽发第一级，高带宽加第二级。消息打成十六个 token 一块的 Morton 微块，丢掉一块不影响其他块，并附带一段粗可见性包络。B0 到 B4 共用骨干、解码器和打包器。共享码本基线只借用 SAVQ 的机制，不使用多相机骨干。

3. 由发送车射线生成的三态占据。0 是 Unknown，1 是 Observed Free，2 是 Occupied。未知体素上的语义损失使用 `ignore_index`。没被射线看见的格子保持未知。Semantic-OPV2V 里因为没扫到而填 0 的格子，不当成空闲。没传到的体素也不是安全空闲。

## Related Work 缺口段

协同语义占据和离散通信已经各有系统，但对不上「接收车没有环境观测」这一条。CoHFF（CVPR 2024）和 VQSOP（ECCV 2026）的网络输入是多相机，不是激光雷达。Semantic-OPV2V 的 4LidarSurround 提供语义激光雷达标签，不能当作这些网络的输入。检测框表达不了道路和自由空间，原始点云和稠密特征又超出有限带宽。共享码本说明特征可以离散化，只发占据锚点却分不开「看见的空」和「没看见」。LiDARWeather 是训练期的选择性抖动和丢点，不是天气测试集。天气测试要使用与训练增强分开的 LISA 物理模型。缺口因此是：在接收车自身没有环境观测时，用同一套骨干、解码器和打包器，把几何码和粗可见性放进有限字节，并强制没传到的体素保持未知。

## 章首过渡句

### Introduction

拥堵路段上同时有带着激光雷达的车，和没有环境传感器的车。现有协同感知默认每辆车自己还能看见，邻车消息只是在补充。这个默认拿掉之后，问题收成一句：没有本车环境观测时，邻车消息是唯一证据；没传到的体素不等于安全空闲。

### Related Work

上一节把任务收成证据问题。相关工作里已经有协同通信，也有语义占据，但输入模态、空闲的含义和天气协议都还停在「本车自己有传感器」。本节只核对三组工作：协同感知与通信、协同语义占据、离散表示。

### Problem Formulation

方法是否成立，先看接收车被允许使用什么。本节规定发送车集合、接收车输入、坐标系和消息预算，并规定 Unknown、Observed Free、Occupied 只由发送车自己的激光射线生成。

### Method

证据从哪来已经规定完了。本节规定这些证据怎么变成字节：纯 PyTorch 编码，三组几何码本上的残差向量量化，十六个 token 一块的 Morton 微块，再加上一段粗可见性包络。隐式射线雕刻可以留下，但不能代替这段包络。所有对比方法共用同一套骨干、解码器和打包器。

### Experiments

方法有没有把可见性放进字节里，要在同一字节预算下和四条基线比，而不是和另一套更大的网络比。顺序是先看邻车射线实际覆盖多少，再训练。训练期只做轻量抖动和丢点。天气测试另用 LISA 的物理退化，参数与训练增强分开。真实日志写出来之前，这里不填精度。

### Limitations

后面的比较即使成立，系统也只是在借用邻车已经看见的部分。没有人看见的目标不会被解码器变出来。通信断开时，它不能代替本车的安全传感器。
