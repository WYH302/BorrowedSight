## 一、统一主线、形式化理论与五大高 ROI 核心升级

**核心论点**：在零冗余 5 字节（40-bit）线缆记录（`17b 无损坐标 + 4b 显式类别锚点 + 6b code1 + 6b code2 + 7b 置信度`）中将 4-bit 语义类别 $c_u$ 显式上链，在**总参数量（2.419M / 16.71 GFLOPs）低于等字节 CodeFilling-Occ（2.462M / 17.61 GFLOPs）**的前提下，同步解锁三大**零额外线缆字节**接收端机制，并由第四节 **4 项闭式命题（Propositions 1–4）** 给出比特打包最优性、高码率量化失真界（Gray & Neuhoff T-IT'98 + Minkowski 行列式不等式）、SS-KFW 运动学延迟位移界及渐近通信/计算复杂度证明：

1. **$D_4$-Equivariant `SenderEncoder`（0 额外字节）**：7 通道 `scatter-mean/absmax/log-density` 池化 + GroupNorm + 2D 正弦位置编码 + Masked Lovász-Softmax + Warmup + EMA（`1.172M` 参数、`7.65 GFLOPs`、`0.49 GPU-h`、`0.40 GB` 显存），将发送端验证集 mIoU 从 `0.7150 → 0.7657`（`+5.07 pt`）、留出测试集 mIoU 从 `0.7547 → 0.8595`（`+10.48 pt`，Building `0.2489 → 0.8259`）。
2. **满位宽 $3\times 64$ 加法式 ResidualSimVQ + 零同步单 GEMM 向量化（0 额外字节 / 0 额外可训练参数）**：吃满 6-bit 免费位宽（`K=64`），单次 batched GEMM 实现 **`6.73×` 加速**（`0.00e+00` 数值一致性）；Stage-2 活跃原型达 **`149/192 (77.6%)`**，其中 Vertical Static 达 **`63/64 (98.4%)`**（困惑度 `33.14`、归一化熵 `0.842`）。
3. **语义锚点残差直连 `SARC`（0 额外字节 / 仅 `+13` 标量参数）**：置信度与时效加权的线缆类别投票（训练期 25% 体素 prior dropout）以有界类门控 $4\sigma(\alpha_c)$ 直接注入 3D 语义 logits，彻底消除 2D BEV U-Net 解码模糊，一举将测试集 Building IoU 拉升 **`+18.69 pt`**（`0.2130 → 0.3999`，3 种子 **`0.4338`**），整体 mIoU 提升 **`+2.29 pt`**。
4. **语义选择性运动学前向补偿 `SS-KFW`（0 额外字节 / 0 参数）**：纯 NumPy 接收端 8 邻域 BEV 聚类 + 多步时滞加权速度估计，仅前向映射 `c_u == Vehicles` 动态锚点而锁定全部静态建筑/道路世界 $\mathrm{SE}(3)$ 坐标，将 **500 ms 延迟车辆 IoU 提升 `3.49×`**（`0.0571 → 0.1994`，为 `CodeFilling-Occ` 的 `3.67×`、`B3-VQ` 的 `6.19×`）。
5. **自适应 `50×50` Zstd 包络 + 任务解耦可见性融合 `TDVF`**：在 4,736 条真实 OPV2V 扫描与 **2,306 条实车 V2V4Real 32 线扫描**中均实现 **100.0% 无溢出封装（0.0% overflow）**；TDVF 隔离早融合几何捷径过拟合（**`+2.92 pt`** 测试 mIoU），使全部 **9/9 正交消融严格正向**。
